# plans/

Local design docs for this repo — plans whose entire implementation lives
here. See [`deb2lbf/plans/plan-distribution.md`](https://github.com/relations-foundation/deb2lbf/blob/master/plans/plan-distribution.md)
for the ecosystem-wide convention (every repo gets a `plans/` directory, even
if empty — a consistent answer to "where does a repo-local design doc go"),
and `deb2lbf/plans/README.md` for the general plan-file structure.

Completed plans move to `plans/archive/` in this same repo (not back to
`deb2lbf`) — distribution is one-way; this repo owns a plan's whole
lifecycle once it lands here.

Empty for now — no repo-local plan has been added here yet.
