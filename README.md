# relationsfoundation-comments

Hosts GitHub Discussions for the [relationsfoundation.org](https://relationsfoundation.org)
page-comment widget (giscus) and the Luca Bot discussion-reply automation.

This repo intentionally holds no site source or application code beyond the
`luca-bot.yml` workflow — it exists only because giscus requires its mapped
repo to be public, and `relationsfoundation.org` itself is private.

See `relationsfoundation.org/AGENTS.md` § GitHub Access Gate and
§ Luca Bot Integration for the full picture.
